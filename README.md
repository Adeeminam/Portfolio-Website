# Adeem Inam — SQA Portfolio

A responsive single-page portfolio for an Associate SQA Engineer.

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## Customize before publishing
1. Replace the LinkedIn `#` with your real LinkedIn URL.
2. Replace the GitHub `#` with your real GitHub URL.
3. Add your final CV as `Adeem-Inam-CV.pdf` and add a Download CV button if desired.
4. Only keep the practice projects on the portfolio if you actually complete them; label them as practice/portfolio projects.
